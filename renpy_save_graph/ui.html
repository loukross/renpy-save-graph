Evaluated against each node's diff from its parent. When the expression evaluates false, the node's lineage is marked invalid.
Functions:
  • delta('var') — Change in value vs parent node
  • changed('var') — True if variable changed
  • changed('var', from, to) — Changed from value to value
  • added('var') — True if newly created on this node
Comparisons & Logic:
>, <, >=, <=, ==, !=, && (AND), || (OR), ! (NOT)
karma >= 10 && delta('money') > 0
karma — Matches variables containing "karma"
^day — Starts with "day" (e.g. day_num)
score$ — Ends with "score"
(karma|gold) — Matches "karma" OR "gold"
^[^_] — Excludes system vars starting with _
Note: Matching is case-insensitive by default.
Milestone variables are game state variables used to align save points across separate subtrees onto shared vertical milestone columns.
Rule for Story Progress Variables:
Milestone variables must represent monotonically progressing story markers (e.g. currentEpisode = 1, 2, 3... or chapter).
Variables that fluctuate, decrease, or revert to previous values (like gold, health, or temporary state flags) should not be used, as non-monotonic values produce unpredictable layout jumps and branch misalignments.
